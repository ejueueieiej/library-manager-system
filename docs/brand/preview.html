文件位置

矢量源文件在 docs/brand/svg/，坐标写在 tools/gen_logo.py 里，改完重跑脚本，不要手改 SVG—— 星芒控制点与居中补偿都是算出来的。

落地方式

把 mark-d-shelf-books.svg 与 mark-d-shelf-books-compact.svg 复制到 library-web/public/brand/；index.html 加 <link rel="icon" href="/brand/favicon.svg">； 侧栏 MainLayout.vue 的 .brand-mark 换成该 SVG。

还差一步

网页里的字标用真实 HTML 文字渲染（更清晰、可被搜索），所以不需要转曲； 但若要做印刷 / 对外物料，需要按最终字体把「星河图书」描边转曲， 再产出一份独立的 lockup SVG。
